# 20260517_tea-shop — 茶葉購物網站

## 目的

建立一個茶葉購物網站專案，提供茶葉商品瀏覽、購物車與結帳體驗。

## 規劃方向

- 商品目錄：分類（綠茶、紅茶、烏龍、普洱、花草茶等）、商品詳情、圖片與品飲說明

- 技術：待定（前端 / 全端框架選型於開工前確認）
